# Character portraits

Drop any number of images into each character folder. Filenames can be anything.

Supported browser formats include PNG, JPG/JPEG, WebP, AVIF, and GIF. Odd extensions such as `.jpg_large` are also discovered. Recommended: portrait orientation, at least 800 × 1000 px, with the face near the upper center.

The dev server notices new or removed files, refreshes the app, and randomly picks one available portrait per character. That choice remains stable for the current browser session. Close and reopen the tab to get a new random selection.
